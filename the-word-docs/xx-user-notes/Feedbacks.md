Having folders to add verses. This can integrate well with the search-by-highlight system we already have envisioned, so we add a tag to a verse (or a span of words), and then the user can query by tags. And not necessarily the tag has a display color, so not necessarily the saved verses need to have color. This decouples color matching from verse bookmarking, in a way that let's the user freely highlight and still freely bookmark what they need to.
