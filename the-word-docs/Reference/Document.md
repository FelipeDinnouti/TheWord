Features:
1. Infinite Scroll
2. Rich Text

### Foundation

Document: The laid-out strucutre of the text.

Scroll position: the current sliding window position, relative to the document start, which is always 0. Document coordinates, in px. 

Document height: The total size of the document.

Anchor-fixed behaviour: whenever text is prepended, the visible text should not jump. To do that, add the height of the prepended text to the scroll position.
