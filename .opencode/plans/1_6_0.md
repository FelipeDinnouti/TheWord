# v1.6.0-alpha.1 — Inertial Scroll Rewrite

## Goal
Replace the overcomplicated inertial scrolling (delta-history ring buffer + EMA + double exponential smoothing) with a simple quadratic-drag physics model.

## New Physics Model

- **Touch drag**: `scrollY` follows finger exactly (`direct=true`)
- **Launch**: `launchVelocity = lastFrameDelta / GetFrameTime()` on finger release
- **Momentum**: `v /= (1 + DRAG * |v| * dt)` (analytic quadratic drag, stable) + `scrollY += v * dt`
- **Stop**: `|v| < VELOCITY_EPSILON` → zero
- **Wheel/keyboard**: delta contributes to `v` for light inertia
- **No double smoothing**: everything happens in DocumentManager, single pass

## Changes

| File | What |

| `src/document/DocumentManager.cpp` | Rewrite `OnScroll` and `Update` for single-pass physics integration. |

## Constants (tunable)

- `DRAG = 0.008f` — quadratic drag coefficient (lower = longer glide)
- `VELOCITY_EPSILON = 10.0f` — px/s threshold to stop momentum
- `MAX_VELOCITY = 5000.0f` — sanity cap on launch velocity
- `SCROLL_SENSITIVITY = 40.0f` — unchanged (wheel px per notch)
- `KEYBOARD_SCROLL_FACTOR = 0.3f` — unchanged
